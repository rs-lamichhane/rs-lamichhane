# 👨‍💻 Rabins Sharma Lamichhane

**Cyber Security Researcher | SRE & Software Engineer | MSc Candidate (RGU)**

I bridge the gap between large-scale software engineering and advanced cyber security research. With a strong foundation in Site Reliability Engineering (SRE) and IoT backend development, my current focus lies at the intersection of **Zero-Trust Architectures**, **Autonomous Threat Inference**, and **Decentralized Identity**.

### 🔬 Current Research Interests
*   **Autonomous Threat Response:** Leveraging SOAR and AI agentic frameworks to transition SOCs from reactive alert triage to proactive, autonomous containment.
*   **Advanced Intrusion Detection:** Exploring kernel-space network anomaly detection using **eBPF** (Extended Berkeley Packet Filter) to bypass user-space overhead.
*   **Privacy-Preserving Compliance:** Implementing **zk-SNARKs** (Zero-Knowledge Proofs) for decentralized, zero-trust smart contract compliance auditing.
*   **Decentralized Identity (SSI):** Working with W3C Verifiable Credentials and DIDs to secure identity-centric threat environments.

### 🏆 Featured Capstone Projects
*   [**`autonomous-threat-response-agent`**](https://github.com/rs-lamichhane/autonomous-threat-response-agent) — A conceptual SOAR agent framework simulating identity-centric threat inference and automated MITRE technique isolation.
*   [**`zk-snark-smart-contract-verifier`**](https://github.com/rs-lamichhane/zk-snark-smart-contract-verifier) — On-chain verification of Groth16 cryptographic compliance proofs via Solidity, developed as part of my MSc dissertation research.
*   [**`ebpf-network-anomaly-detector`**](https://github.com/rs-lamichhane/ebpf-network-anomaly-detector) — Elite-level Linux kernel tracepoint hooking utilizing BCC for zero-overhead, socket-level TCP intrusion detection.
*   [**`live-threat-intel-cli`**](https://github.com/rs-lamichhane/live-threat-intel-cli) — A fully functional CLI tool that tails system logs, maps attacking IPs via live Geo-API resolution, and maintains an SQLite persistence layer.
